# From a breeding plan to a useful family

Implemented 2026-10-20 under the active cohesion plan. This joins the existing
Table, real litter seeds, living offspring, care and commissions. There is no
new currency, inventory, animal stat or mandatory task.

## Plan, produce, measure

Two Table samples forecast a future pair with held feed/treatment/Fortune cues.
**Compare next real seed** instead uses the exact inventory seed shown. Its
saved parents, points, quality and Mutagen treatment supply a `Cross`; original
feed and starborn quality are already included. Held cues cannot rewrite it.
The view identifies whether both parent genomes and points match the samples
in either order, then shows actual goal odds and point targets. Nothing is spent.

Odds are before mutation and crowding, without extra crop Fortune. A Cradle
uses saved quality. A planted crop can gain native Fortune quality when cut;
this readout does not silently promise that future bonus.

**Read litter forecast** opens the existing seed folio from Table or Cradle.
Original overview/parent indices 0–2 stay; a visible overview link opens actual
pup forecast 3, followed by inherited copies 4. Only parent spreads build animal
portraits. The seed payload text is unchanged.

## Find the living family

With actual Calipers in inventory, **Check nearby offspring** lists ordinary
living animals within twelve blocks with the two sampled birth-parent genomes
in either order. The actual-seed view has its own entry using that seed's
parents, even if the samples describe another pair; Back retains that source.

Birth records store parent genomes, not identities, birth dates or parental
points. The view states that several litters can match. It does not fabricate
individual relationships or Tissue Samples. Loaded entity queries do not load
remote chunks. Four animals per page show name, age, position and inherited
gene/point targets met. A courier's later equipment requirement does not reduce
a pup's inherited score. Summaries precede numbered controls in the care layout.
Requested glints close inspection and briefly mark that page's actual animals.

Compare a reachable animal to open its exact native container with the Table
goal. Changed samples, goal, inventory seed or family rows invalidate an old
click. The animal then has normal six-block reach, world, removal and owner-session
checks. No client-provided entity or item can replace the selected target.

## Raise a suitable offspring

**Useful roles & work → Compare commission goals (Calipers)** also measures
any ordinary animal against all nine requests, including pups. This private
menu choice changes no Table or Board. Losing the real tool hides exact results
and refuses old measurement actions. Adventure can inspect; no comparison
submits a form or changes animal care.

The real request supplies gene-copy, signed-point and equipment checks.
`CommissionCandidate.condition` shares native living-adult, parent, health,
transport and calm rules with the Board. Irreversible genes/point misses suggest
another role, mate or goal. Even a fitting wild pup immediately warns about
missing birth records. Promising parented pups lead to growth, then adult
health/calm/cargo and the same request at a staffed Board.

Care shows approximate loaded growth time from actual age and Bloom, before
future meals. Native golden-dandelion locking now pauses vanilla aging and
Bloom's extra age ticks. Care/advice/guava hints identify the paused state.
Flower payment, cooldown, age reset and saved `AgeLocked` remain native.

## Materials before specialization

Table, Board and Breeder's Pen accept ordinary feathers or legacy Whiskers
through `bunnidogs:workshop_quills`. Shapes and other costs stay. Native recipe
unlocks recognize the tag. Requiring Senses +10 material before planning or
staffing another specialty made the purpose loop depend on an unrelated line.
First-litter rewards also reveal Table, Syringe and Ear Tag recipes; no milestone
gates crafting or care. Healthy pups already support sampling; hints now say so.
Seven existing guide entries changed, with no appended pages or indices.

## Evidence and compatibility

Java 25 build, focused breeding-lab checks and all **107** native cases pass at
integration. The added family scenario uses deterministic actual seed hatching,
matching/reversed/unrelated births, pagination/stale rows, exact live selection,
private Adventure comparisons, lost tools, paid golden dandelions, a paid care
meal and actual Board rewards. It fast-forwards the long wait before the final
native adult age step; this does not establish growth pacing.

The same fixture checks actual-seed/held-cue separation, saved parent points,
all nine bounded views, replaced seed refusal, the native payload and read-only
Cradle access. Existing first-litter coverage crafts Table/Board/Pen with both
feathers and Whiskers. Focused maths keeps actual quality/treatment without a
second starborn bonus, derives expected points from native drift and checks pages.

Seventeen server snapshots and exported seed/goal layouts feed substitute-font
previews. Client fonts, markers, keyboard comfort, natural resources and new-player
understanding still need Survival playtesting. No new saved fields or packet
shapes are introduced. Protocol **17** remains; use the current build on both
sides for the new text and folio. Existing animals, seeds, samples, bundles,
Table goals, allele order and personal commission progress retain their formats.

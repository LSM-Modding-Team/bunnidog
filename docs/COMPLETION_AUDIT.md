Earlier core breeding, workstations and exploration, requested UI corrections,
shared Spanish, the accepted Apex roles/wings, Great Warren/Astralite,
Crown/gear and operator kits have implemented playable slices. Their natural
world/client evidence and optional extensions must not be conflated with missing
implementation or used to justify rebuilding accepted systems.

## Continuation order

1. Make existing procedures survive teacher loss through real teaching/records.
2. Expand complementary professions and needs/dependency coordination.
3. Complete useful construction handoffs/repair, then wild-family bootstrap.
4. Build functioning wild settlements before inter-community exchange.

Newly reported bugs and player experience still take precedence. Keep low-end
animals useful, actual material costs/permissions, inherited limits and learned
skills separate, and avoid replacing discoverable gameplay with tutorial UI.
